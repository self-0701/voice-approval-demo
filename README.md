# 声证 / 音色授权与第三方审查平台

配音员签发授权，制作方上传外部完成的音频，第三方机构试听并决定，接收方用交付回执核验收到的文件。

## 本地演示

```powershell
npm install
npm run dev
```

打开 <http://127.0.0.1:4173/>。默认配置已指向 Monad 测试网合约；没有钱包时仍可切换到本地账本演示。使用浏览器钱包时，四个角色可以分别连接不同地址，音频保存在 IndexedDB。

1. 在「授权确认」签发第一版授权。改项目、台词或用途时，需要签发另一张授权单。
2. 在「上传送审」关联授权单，选择自己的音频或载入演示样音。可以先改台词版本、项目、用途或提交方，确认系统拦住送审，再恢复到授权范围提交。
3. 在「机构审核」选择送审记录，试听实际提交的音频。核对台词和用途后，勾选确认并选择通过或驳回。通过后可下载交付回执。
4. 在「独立核验」选择或导入回执，导入原始音频，确认显示匹配。换一份音频，确认显示不匹配。

本地的两个 WAV 样例是提示声。需要演示台词和用途的人工审核时，使用制作方实际录好的文件。旧版演示记录留在原浏览器存储中，新流程请重新签发和送审。

## Monad 测试网

1. 在项目目录运行 `npm ci`，安装链上模式所需依赖；`npm run chain:check` 可检查 RPC 和链 ID。
2. 使用 `npm run chain:deploy` 编译并部署 `contracts/VoiceRightsRegistry.sol` 到 Monad 测试网（链 ID `10143`）。部署时使用 `.env` 中的 `MONAD_PRIVATE_KEY`，并将 `REVIEWER_ADDRESS` 设为首个审核员；部署钱包是合约管理员，可调用 `setReviewer` 管理审核员。
3. 页面默认连接当前演示合约；也可以在「网络配置」中填入另一份合约地址与 RPC。写入者使用支持 Monad 测试网的钱包，按角色签发授权、送审或审核。接收方只需连接同一合约即可查询。
4. 配音员将「下载授权单」得到的 JSON 交给制作方。制作方导入授权单，提交后将送审单和原始音频交给审核员。审核员导入两份材料，试听并签发回执。接收方导入回执与交付文件，查询链上的授权人、审核人、决定、授权状态和文件指纹。

合约记录钱包地址、授权范围指纹、授权期限、成品指纹和审核决定。原始音频在浏览器中处理，项目、台词和用途随授权单及送审单在参与方之间传递。审核机构负责判断实际内容，核验页检查文件字节与记录是否一致。链上身份以钱包地址显示。
